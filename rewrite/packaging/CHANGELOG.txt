IMDb Tech Manager v5.0.0

- Migrates only the v4.1.0 stack to Rust + Tauri 2 + TypeScript + Vue 3/Vite. Retains the catalog, Inspector, Specs/Tag ownership, rules and AI, scopes/preview adoption, task logs/recovery and settings without adding product features.
- Provides macOS ARM64 DMG, Windows x64/ARM64 NSIS and Linux x64/ARM64 AppImage/DEB/RPM: five targets and nine packages, with no macOS Intel.
- Preserves old dual-directory, Sidecar, settings, cache, prompt, credential-reference, history and r1 language recovery. Fail-closed startup and NFO transaction safeguards remain.
- Keeps three built-in languages and five complete external r2 ZIPs. Tasks freeze their starting locale, and old logs are not rewritten. About links retain all eight legal-document locales; opening Settings restores the original automatic update check.
- Signs update assets with the existing ITM Ed25519 key, retains the v4.1.0 macOS OTA ZIP/signature and provides the v5 update catalog. DEB/RPM upgrades use the system package manager; no software repository is added.
- macOS is ad hoc signed and not Apple-notarized; Windows has no distribution certificate. Full native operation, pixel and real AI/IMDb acceptance were deferred by the maintainer. Windows/Linux hardware and minimum-macOS runtime are uncertified; source/package checks do not certify system support.
