# プライバシーポリシー

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | **日本語** | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

IMDb Tech Manager はローカルで動作するデスクトップツールです。本製品独自のテレメトリー、広告追跡、アカウントシステムは運用しません。

- 選択したメディアフォルダー、NFO、設定、キャッシュ、タスク履歴はローカルに保存されます。
- 設定を開くか更新確認を選ぶと、GitHub から正式リリースの情報を取得します。更新パッケージのダウンロードはインストールを承認した後に行います。
- AI リクエストは、AI 機能を設定して実際に使用した場合のみ、指定したプロバイダーへ送信されます。事前にそのプロバイダーのプライバシーポリシーをご確認ください。
- IMDb Technical Specifications の取得とローカルライブラリへの操作は、利用者が開始した機能の範囲でのみ実行されます。

更新日：2026-10-04。言語パックは選択時、または起動時に選択済み・インストール済みの言語を復元するとき、対応する GitHub Release から取得します。設定、履歴、プロンプト、旧版の移行アーカイブはローカルに保存し、言語変更で NFO を書き換えません。
