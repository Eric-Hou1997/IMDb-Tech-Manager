# Privacy Policy

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | **English** | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

IMDb Tech Manager is a local desktop tool. It does not operate its own telemetry, advertising-tracking, or account system.

- Media folders, NFO files, configuration, caches, and task records you select are stored locally.
- Opening Settings or selecting Check for Updates connects to GitHub for official release information; update packages are downloaded only after installation confirmation.
- AI requests are sent to the provider you configure only when you enable and actively use AI features. Review that provider's privacy policy first.
- IMDb Technical Specifications retrieval and operations on your locally configured libraries run only as part of features you initiate.

Updated: 2026-10-04. Language packs are downloaded from the matching GitHub Release when selected or when startup restores a selected/previously installed language. Local configuration, history, prompts and legacy migration archives remain on the device; language changes do not rewrite NFO files.
