# Политика конфиденциальности

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | **Русский** | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | [ไทย](./PRIVACY.th.md)

IMDb Tech Manager — локальное настольное приложение. Оно не использует собственную телеметрию, рекламное отслеживание или систему учётных записей.

- Выбранные медиапапки, файлы NFO, настройки, кэш и журнал задач хранятся локально.
- При открытии настроек или выборе проверки обновлений приложение обращается к GitHub за сведениями об официальных выпусках; пакет обновления загружается только после подтверждения установки.
- Запросы ИИ отправляются выбранному поставщику лишь после настройки и активного использования функций ИИ. Сначала ознакомьтесь с политикой конфиденциальности поставщика.
- Получение IMDb Technical Specifications и операции с настроенными локальными медиатеками выполняются только в рамках запущенных вами функций.

Обновлено: 2026-10-04. Языковые пакеты загружаются из соответствующего GitHub Release при выборе языка или восстановлении выбранного/ранее установленного языка при запуске. Настройки, история, запросы и архивы миграции остаются локальными; смена языка не переписывает NFO.
