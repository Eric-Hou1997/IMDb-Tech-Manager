IMDb Tech Manager 是本機桌面工具，不會建立本產品自己的遙測、廣告追蹤或帳號系統。

- 您選擇的媒體目錄、NFO、設定、快取和工作記錄均保存在本機。
- 只有在您手動按下「檢查更新」或確認下載安裝時，軟體才會連線 GitHub 查詢或下載正式發佈資訊。
- 只有在您設定並主動使用 AI 功能時，相關請求才會傳送至您選擇的 AI 服務供應商；請先閱讀該供應商的隱私政策。
- IMDb 技術規格的擷取以及對本機設定媒體庫的操作，只會在您主動啟用相應功能時執行。

本政策會隨正式版本更新；原始碼中的發佈日期預留內容會在對應的正式版本中確定。
