# นโยบายความเป็นส่วนตัว

[简体中文](../../PRIVACY.md) | [繁體中文](./PRIVACY.zh-Hant.md) | [English](./PRIVACY.en.md) | [Français](./PRIVACY.fr.md) | [Русский](./PRIVACY.ru.md) | [日本語](./PRIVACY.ja.md) | [Español](./PRIVACY.es.md) | **ไทย**

IMDb Tech Manager เป็นเครื่องมือเดสก์ท็อปที่ทำงานภายในเครื่อง โดยไม่มีระบบโทรมาตร การติดตามโฆษณา หรือบัญชีผู้ใช้ของผลิตภัณฑ์เอง

- โฟลเดอร์สื่อ ไฟล์ NFO การตั้งค่า แคช และประวัติงานที่คุณเลือกจะจัดเก็บไว้ภายในเครื่อง
- เมื่อเปิดการตั้งค่าหรือเลือกตรวจสอบการอัปเดต แอปจะเชื่อมต่อ GitHub เพื่อดูข้อมูลรุ่นทางการ โดยดาวน์โหลดแพ็กเกจอัปเดตหลังยืนยันการติดตั้งเท่านั้น
- คำขอ AI จะส่งไปยังผู้ให้บริการที่คุณตั้งค่าไว้เฉพาะเมื่อเปิดและใช้งานฟังก์ชัน AI โปรดอ่านนโยบายความเป็นส่วนตัวของผู้ให้บริการก่อน
- การดึง IMDb Technical Specifications และการดำเนินการกับคลังสื่อภายในเครื่องจะทำงานเฉพาะในฟังก์ชันที่คุณเริ่มต้น

ปรับปรุง: 2026-10-04 ชุดภาษาดาวน์โหลดจาก GitHub Release ที่ตรงกันเมื่อเลือกภาษา หรือเมื่อเริ่มแอปเพื่อคืนค่าภาษาที่เลือก/เคยติดตั้ง การตั้งค่า ประวัติ พรอมป์ต์และข้อมูลย้ายรุ่นเก่ายังอยู่ในเครื่อง การเปลี่ยนภาษาไม่เขียน NFO ใหม่
