# 第 5–8 步迁移执行记录

状态：**部分实现，未达到四步整体完成条件，不可替代正式 v4.1.0。** 开发位于 `v5.0.0-rewrite`；本轮没有提交、推送、打 tag 或发布。旧平台代码和正式业务引擎仍保留。

## 已实现的基础和读取链

- `rewrite/src-tauri/core/` 为独立可测试 Rust 核心。Vue → Tauri 命令/事件 → Store/读取用例 → XML/路径/SQLite 适配；两仓库独立构建，不运行时互相引用。
- Rust 生成 TypeScript 类型；配置 revision CAS、数据库版本拒绝降级、单一数据库所有者、持久化操作结果与跨操作种类 ID 冲突检查。
- 扫描任务明确根目录范围和 Movie/TV 空间，冻结启动语言；持久化进度、历史、暂停、恢复、取消、退出中断。恢复从根重新遍历并复用未改变的索引，不是旧引擎游标直接续跑。
- 只读 NFO 解析、根标签权威归属、Technical Specs、同 IMDb 不同路径条目的独立身份。保存 source hash/parser revision，增量刷新；异常路径可定位，离线根保留已有索引。
- Vue 工作台已有根目录选择、显式范围、搜索、异常过滤、分页、选择、Inspector、文件管理器定位、任务状态与控制。Movie/TV 的窗口内搜索和选择各自保留。
- 凭据只有 Rust 接口，原生 keyring 适配；前端没有获取凭据的通用命令。已定义 8 语言注册表、任务语言快照，完整界面翻译和语言包流程尚未接入。
- 本地窗口权限与 CSP 保持隔离，外部网页没有管理命令；工作线程/事件监听/计时器分别持有并清理。退出时等待扫描线程停止。

## 显式差异与限制

- 解析超过 32 MiB 的 NFO、DTD、符号链接/Windows reparse 路径时失败并定位，不擅自修复或绕过；与旧版的全部边界差异尚需逐项对照。
- ITM 归属比较使用 Python 对应的 Unicode full casefold；TCM 保留其原版小写比较语义。ITM 合并已知 Specs 重复 section，TCM 保留最后 section；未将两个产品不同旧行为强行统一。
- 扫描取消在读取检查点生效；网络文件系统阻塞读、权限与锁行为必须真实平台验证。当前单元测试不证明任意网络故障都能即时退出。
- 第 4 步记录的 IMDb HTTP 202、旧 OTA 签名兼容、Emby 权限和更新/卸载验收阻塞继续有效，首发矩阵没有缩减。
- 未迁移功能均仍在 [完整功能台账](features.json)；`partial` 只代表列出的实现片段，不表示整个功能组或原版入口验收通过。

## ITM 写入与 AI/规则实现边界

- `specs.rs` 已实现结构化 IMDb 数据的十字段解析、有效 Specs 指纹、限定 Technical Specs 的候选构建与保护区域验证；没有接入真实网络获取。
- `transaction.rs` 提供备份、候选验证、源 hash CAS、临时文件 fsync/原子替换、操作回执、重试结果查询和校验后撤销。失败注入覆盖备份后、替换前、替换后；测试只在隔离文件运行。
- **写入事务在默认关闭的 `write-prototype` feature 内，桌面应用不编译它，也没有媒体写命令。** Windows 目录同步尚未验证时明确拒绝写入。非协作进程在最后 hash 检查与 rename 之间的竞争、目录描述符约束、Windows ACL、真实断电/网络盘恢复仍待处理；因此不能开放生产写入。
- `ai.rs` 已迁移默认中文提示词、请求约束、OpenAI/Anthropic 请求构建、Qwen thinking/cache 规则、usage 先记账再校验、截断/JSON/schema/鉴权/额度/限流分类，以及改变输出上限和重复失败跳过策略。当前是纯策略模块；没有真实 HTTP、持久化金额账本、完整缓存和任务编排。
- `rules.rs` 已实现六个派生字段、Camera 顶层分隔/Series 展开/跨品牌镜头拆分/场景注释清理、音轨和比例规则，以及大小写去重与来源索引。它只生成候选，不授权删除或写入任何标签。
- `/usr/bin/python3 tools/rewrite/differential.py` 直接调用保留的旧 Python 纯函数，与 Rust 的真实 NFO、请求/默认提示词、结构化数据和 Camera/规则边界样例比较。AI 请求中的紧凑用户 JSON 按对象比较；序列化键顺序不同可能改变缓存字节，迁移缓存必须用新命名空间，不能无说明复用旧键。
- Generated 手动转 Manual、外部标签显式删除、sidecar 原子次序、旧备份导入/撤销和全部规则写入流程仍未迁移完成。不能据此宣称 ITM 台账全部实现，也不能删除旧 Go/Python 引擎。
