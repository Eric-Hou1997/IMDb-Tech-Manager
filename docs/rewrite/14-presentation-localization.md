# ITM Manager 展示语言迁移

状态：2026-09-13，本地基础实现已测试；完整八语言目录、原生接口与界面尚未接通。不得据此声明 Manager 八语言完成。

## 已实现边界

`rewrite/src-tauri/core/src/presentation.rs` 校验应用编译目录与展示语言包：产品、schema、应用版本、消息集摘要、修订、唯一资产名称及原始字节 SHA-256 必须匹配。外部包只允许消息文本，拒绝未知控制字段、覆盖内置语言、缺项或多项、占位符与受保护词变化、错误目标文字及超限资源。动态标题、路径、NFO、协议字段和自定义提示词不进入翻译。

新迁移格式为 schema 2 JSON，资产名称 `ITM-Language-<locale>-r<revision>.json`。这是重写工程的候选格式，尚无对应已发布资产；旧版语言包及发布目录保持原样。最终版本每个外部语言绑定唯一描述符，未改变的资产可引用较早版本；运行时不逐个探测历史 Release。编译目录必须来自应用自身，未来原生命令不得接受下载方提供的替代目录。

SQLite 仅缓存经验证的公开资源，按原始摘要寻址；读取重新验证，重复安装幂等，损坏缓存仅由明确安装的有效候选修复。安装不改变活动语言、资料库配置、NFO 或任务。前端展示模板通过文本绑定输出，动态值只插入一次；已开始工作捕获独立语言模板，后续切换不改变它。该机制尚未接入实际任务日志。

## 当前证据

两产品分别执行核心 `presentation` 7 项、Node 展示模板 4 项并通过，包括真实 SQLite 安装与重启、缓存损坏修复、媒体及配置不变、错误包拒绝、未安装语言禁止激活、任务模板固定和动态值不被二次解释。Vue/TypeScript 构建通过。测试使用合成小目录，不是正式全文翻译质量或原生安装验收。

`rewrite/tools/presentation-inventory.mjs` 只生成源码候选清单，包含需要人工排除的机器键和需要合成完整句子的动态片段；不能作为完整覆盖证明或直接替换全部字符串的脚本。
