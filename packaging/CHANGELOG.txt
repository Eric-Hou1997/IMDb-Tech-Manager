IMDb Tech Manager macOS v4.0.2

- About shows the actual September 2, 2026 release date instead of placeholder text.
- Opening Settings checks GitHub once for an official update and shows checking, up-to-date, update-available, or failure state in Software Update.
- Update checks are guarded against duplicate concurrent requests.
- Split-pane position, table column order and widths, Task Center expansion, and CLI height persist across launches; the native layer validates and restores window size and position.
- Movie and TV responsive toolbars, status-filter sizing, headers, and columns share consistent behavior without premature wrapping or overlap.
- Preview navigation aligns with the list header and marks the active tab with a short yellow line.
- Buttons, selectors, and structural headings do not select text; explanatory, status, and content text remains copyable.
- Background mode after app launch and launching the app after login are independent; old settings migrate safely.
- IMDb cache limits (default 2048 MB, range 64–65536 MB), usage state, cleanup, and LRU maintenance were added. Cleanup avoids symlinks, unknown files, and in-use entries.
- Raw IMDb cache entries are validated, and WAF or rate-limit failures remain explicit instead of being mistaken for missing Technical Specifications.
- Batch approvals wait and refresh by immutable task ID, while overlapping jobs fail explicitly.
- Local Rules generation and previews use the 4.0.0 rules identifier. Results must be previewed again after that identifier changes.
